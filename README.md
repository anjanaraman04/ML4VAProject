# ML4VAProject

## Overview
This project analyzes Virginia car crash data to develop a predictive model that estimates accident
severity (ranging from minor injuries to fatal outcomes) based on real-time conditions. Testing with
both of the machine learning techniques LinearSVC and Random Forest, the system integrates diverse
factors including weather, time of day, passenger count, and trip distance to accurately forecast crash
severity levels (K, A, B, C, O). The goal is to provide Virginia drivers with data-driven safety insights
by identifying high risk factors correlated with greater crash severity, helping them make informed
decisions and reduce accident risks, initially through a model’s prediction that could eventually be
integrated into a mobile application for users.

Models run on the data were split into two files for convience and readiblity as well as data leak prevention.
